# Obsidian Model Converter
## What is Obsidian Model Converter?
Obsidian Model Converter (ObMdlCvtr/obmdlcvtr) is a CLI/GUI-based tool for converting standard file formats into the Obsidian-supported model format.

## What is Obsidian Model Format?
The Obsidian Model Format (OBMF/obmf) is the file format and file extension used for any and all textures loaded into the obsidian engine.

## Command-Line Arguments
## Command-Line Arguments
```
    -g      graphics mode
    -o      set output path
    -x      delete origin image
    -v      verbose mode
    -l      set log output path
    -f      input file format
    -q      quiet mode
```

## Usage
```bash
obmdlcvtr.exe -f MDL -v -x -o example.obmf example.mdl -l example.log  # png, verbose mode, delete origin, output specified, log output specified
obmdlcvtr.exe -f OBJ -q example.obj -l example.log  # png, verbose mode, delete origin, output specified, log output specified
obmdlcvtr.exe -g                                        # for window
```
